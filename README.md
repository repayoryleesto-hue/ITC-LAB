# Food Trail Park | Metro Manila

## Project Overview
Food Trail Park Manila is a front-end web application developed as an ITC Lab Project. It is designed to help students, locals, and food enthusiasts discover popular food parks, street food strips, and hidden culinary hubs across key districts in Metro Manila such as Sampaloc, Quiapo, Binondo, Makati, and Pasig.

## Key Features
* District Filtering: Easily filter food parks and culinary spots by specific Manila districts.
* Search Functionality: Real-time search bar to look up specific spots or favorite dishes.
* Interactive Modals: Detailed view for each food spot containing operating hours, addresses, popular food items, and one-click direct navigation to Google Maps.
* Multimedia Integration: Includes an interactive Lofi Ambient Audio Player and a Food Trail Video Showcase.
* Community Suggestion Form: Allows users to submit and suggest new food spots to the directory.
